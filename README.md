# 英语小城 · 探员任务

面向两名小学二年级学生的平板英语闯关练习。当前包含一上、一下、二上共 30 个可玩探索单元。

- 听音识图、拼句、角色表达、场景迁移和可选语法挑战。
- 狐狸阿洛与兔子米米分别保存学习进度、积分、心愿和兑换记录。
- 家长可设置 PIN，给心愿定价，上架或下架奖励，处理兑换。
- 录音只在当前页面临时回听，不上传、不保存，也不自动评分。
- 每个单元都有主题听音、拼句、角色表达、场景迁移、互动语法演示和可选拓展。

网页版：[打开游戏](https://bingo19890910.github.io/english-town-mission/)

## 保存方式

所有家庭记录只保存在当前设备、当前浏览器的本地存储中。无需账号或在线数据库，两台平板各自独立，记录不会共享或自动合并。

GitHub Pages 只发布网页，不保存进度。清除网站数据、使用无痕模式、更换浏览器或更换设备都会导致当前记录无法自动恢复。建议家长在“积分心愿 → 家长管理”中定期导出 JSON 备份；备份包含学习进度、积分、心愿、奖励和兑换，不含 PIN 与录音。当前版本支持导出留存，暂不提供网页内自动导入。

游戏中的词语、完整句子与插画是围绕已确认单元主题制作的原创练习材料，不是教材课文原文。目录来源及使用边界见项目参考资料。
